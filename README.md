# Roster Run (prototype)

Clickable prototype for rostering bus drivers, driver assistants and buses onto routes. **All data is fake demo data** – people, regos and places (Kellerton, Wattle Creek, Silverleaf Valley etc.) are fictional, stored in the browser's localStorage. Use "Reset demo data" to start over.

Static site – no build step. Open `index.html` via any static host (e.g. GitHub Pages) or `python3 -m http.server`.

Files: `index.html`, `styles.css`, `app.js`, `icon.svg`, `apple-touch-icon.png`, `favicon-32.png`, `icon-192.png`, `icon-512.png`, `manifest.webmanifest`.
